# CLAUDE.md

Guidance for Claude Code when working in this repository.

## What this repository is

**tetrak-easyocr-armenian** ships the Armenian recognition model for
EasyOCR. It is the distribution third of a three-repo arrangement decided
in Tetrak's ADR 001 (product zone, private):

- **tetrak-hy-trainer** (public) *produces* the model — its output
  arrives here as a pull request carrying weights and provenance.
- **This repo** (public, Apache 2.0) *ships* it — the `tetrak_hy` import
  package, the packaged network config, and the weights as GitHub
  Release assets. A weights release **is** a library release: one
  version number covers wheel, weights and provenance together.
- **Tetrak** (the pipeline behind [tetrak.dev](https://tetrak.dev/))
  *consumes* it as the `easyocr-hy` backend, like any other engine.

The audience is EasyOCR users, most of whom will never hear of Tetrak.
Write the README and errors for them.

## Hard rules

### The import package is the loading contract

EasyOCR resolves `recog_network="tetrak_hy"` with
`importlib.import_module("tetrak_hy")`, which finds **this installed
package**. That carries obligations:

- The package name stays `tetrak_hy` — renaming it breaks every user.
- `tetrak_hy.Model` stays a class accepting
  `Model(num_class=..., **network_params)` with weights-compatible
  internals. It is a re-export of `easyocr.model.vgg_model.Model`
  (Apache 2.0); never replace it with a hand copy that could drift from
  the class the weights were trained for.
- `tetrak_hy.yaml` ships as package data and must stay consistent with
  the released weights: its `character_list` length + 1 is the model's
  `num_class`. The yaml is *generated by the trainer* and arrives with
  the weights PR — never hand-edit it here. A charset change is a new
  model version, never a patch.
- The model is CTC-headed; EasyOCR's custom-model decode path is
  CTC-only.
- `reader()` constructs `easyocr.Reader` with `["en"]`, never `["hy"]` —
  EasyOCR has no `hy_char.txt` and the language setting is provably
  inert for custom models (the decode filter is
  `set(model charset) − set(lang_char)`, and `lang_char` always includes
  the yaml's full `character_list`). This quirk is this package's
  problem to hide; it must never leak into user-facing docs as something
  users must do (except the "wire it yourself" note in the README, which
  explains it).

### Weights discipline

- Weights are **never committed**; they are GitHub Release assets.
- `WEIGHTS_URL` and `WEIGHTS_SHA256` move together — a URL without its
  checksum must never ship, and a failed checksum refuses installation
  rather than warning.
- Every release carries the trainer's provenance record (data recipe,
  fonts, crop counts, training config, git SHAs) in its release notes.
- The Armenian Soviet Encyclopedia training data is CC BY-SA 3.0 from
  Armenian Wikisource; the attribution travels in the release notes and
  the README's provenance section.

### Quarantine (inherited from the trainer)

Nothing derived from the CC BY-NC `portmind-armenian-ocr` fork —
code, annotations or weights — may enter this repository, and
contributions derived from it cannot be accepted. See the trainer's
CLAUDE.md for the full rule.

## Conventions

- **British English**; sentence case for headings.
- **Conventional Commits**, enforced by `.githooks/commit-msg`
  (`git config core.hooksPath .githooks`, or `lefthook install`).
- **Ruff** with the explicit rule set in `pyproject.toml`.
- Python floor follows EasyOCR's supported range (3.9+), not the sibling
  repos' 3.11 — this library runs in other people's environments.
- CI installs `[dev]` only and must stay torch-free: tests that need
  easyocr guard with `importorskip` and are exercised locally.
